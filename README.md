## 🚀 Overview & Key Highlights

This is the official portfolio repository of **Harsh Agarwal**, engineered with modern WebGL-inspired canvas visualizers, dynamic dual-theme aesthetics (Dark Cyberpunk & Executive Titanium Light), 3D perspective physics, and high-performance React architecture.

- **Dual-Theme Engine**: Seamless one-click toggle between **Cyber Dark Mode** (`#000000`, neon `#00f0ff` & `#ff007f`) and **Executive Light Mode** (`#f8fafc`, royal sapphire `#0062ff`, and pure white elevated cards).
- **3D Physics Tilt Engine**: Real-time cursor angle calculation with dynamic inverse shadow projection and holographic specular sheen.
- **Dynamic 3D Particle Constellation**: Multi-depth background particle matrix and wireframe octahedra that adapt colors dynamically to active themes.
- **Educational Progression Roadmap**: Interactive 3-stage visual stepper (Class X -> Class XII & JEE Adv -> B.Tech CSE AI/ML) with animated energy pulses and continuous marquee ticker.
- **Integrated CV Showcase**: Interactive modal PDF viewer and 1-click download of verified resume.
- **Verified Credentials & Zoom Modal**: High-resolution certificate examinations with instant lightbox zoom.

## ⚡ Quick Start & Local Development

### 1. Clone the repository
```bash
git clone https://github.com/HarshAgarwal895613/Portfolio2.git
cd Portfolio2
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start local development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```
